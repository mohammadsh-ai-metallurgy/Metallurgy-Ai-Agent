## 🚀 پروژه ۱: محاسبه‌گر تعادل فاز و قانون اهرم (Lever Rule)

در این پروژه پایه، یک ابزار متالورژیکی با پایتون پیاده‌سازی شده است که به صورت خودکار درصد فازهای جامد و مایع را در مناطق دو فازی نمودارهای تعادلی پیش‌بینی و محاسبه می‌کند.

### 🛠️ ویژگی‌های کد:
- محاسبه دقیق درصد فازها با دریافت غلظت کل ($C_0$)، مایع ($C_L$) و جامد ($C_\alpha$).
- دارای سیستم خطایابی منطقی برای بررسی قرارگیری غلظت کل در بازه مجاز.
- پیشگیری از خطای ریاضی تقسیم بر صفر (ZeroDivisionError).

### 🔬 کاربرد متالورژیکی:
این فرمول، پایه و اساسی در متالورژی فیزیکی و ترمودینامیک مواد برای تعیین میزان فازها در حین انجماد آلیاژها است.

# پروژه ۲: رسم نمودار تنش  کرنش و محاسبه خواص مکانیک
مشخصات اولیه نمونه استاندارد تست کشش (ورودی متالورژیکی)

L0 = 50.0  # طول اولیه نمونه به میلی‌متر (Gauge Length)
d0 = 12.5  # قطر اولیه نمونه به میلی‌متر
A0 = 3.1415 * (d0 / 2) ** 2  # محاسبه سطح مقطع اولیه (mm^2)

# داده های فرضی دستگاه تست کشش (نیرو به نیوتون و تغییر مکان به میلی متر )
# این داده‌ها رفتار یک فولاد نرم با پدیده تسلیم را نشان می‌دهند
force_data = [0, 10000, 20000, 30000, 35000, 35200, 35100, 36000, 42000, 45000, 43000, 38000]
displacement_data = [0, 0.05, 0.10, 0.15, 0.20, 0.25, 0.35, 0.50, 1.0, 2.0, 3.0, 4.0]

# لیست‌های خالی برای ذخیره تنش و کرنش
strains = []
stresses = []

# تبدیل داده‌های خام به تنش و کرنش با یک حلقه ساده
for i in range(len(force_data)):
    # محاسبه کرنش (تغییر مکان تقسیم بر طول اولیه)
    strain = displacement_data[i] / L0
    # محاسبه تنش (نیرو تقسیم بر سطح مقطع بر حسب مگاپاسکال یا N/mm^2)
    stress = force_data[i] / A0
    
    strains.append(strain)
    stresses.append(stress)

# --- بخش جذاب: رسم نمودار با Matplotlib ---
plt.figure(figsize=(8, 5)) # اندازه پنجره نمودار
plt.plot(strains, stresses, marker='o', color='red', linestyle='-')

# زیباسازی نمودار مهندسی
plt.title("Engineering Stress-Strain Curve (Steel Sample)")
plt.xlabel("Engineering Strain (mm/mm)")
plt.ylabel("Engineering Stress (MPa)")
plt.grid(True) # فعال کردن خطوط شطرنجی نمودار

# نمایش مقادیر مهم در خروجی متنی
uts_value = max(stresses)
print(f"--- نتایج تحلیل خواص مکانیکی ---")
print(f"سطح مقطع اولیه نمونه: {A0:.2f} mm^2")
print(f"استحکام نهایی کشش (UTS): {uts_value:.2f} MPa")



پروژه سوم: سیستم ارزیابی تشکیل محلول جامد (تئوری هوم-رcurrent / Hume-Rothery Rules)
در متالورژی فیزیکی، قوانین «هوم-رcurrent» به ما می‌گن که آیا دو عنصر می‌تونن با هم محلول جامد کامل (مثل مس-نیکل) تشکیل بدن یا نه. این قوانین بر اساس ۴ فاکتور اساسی هستند:

تفاوت شعاع اتمی: باید کمتر از ۱۵ درصد باشه.

ساختار کریستالی: باید یکسان باشن (مثلاً هر دو FCC).

الکترونگاتیوی: باید به هم نزدیک باشن تا ترکیب بین‌فلزی تشکیل نشه.

ظرفیت شیمیایی: بهتره ظرفیت‌ها به هم نزدیک باشن.

ما می‌خواهیم برنامه‌ای بنویسیم که مشخصات دو عنصر را بگیرد، این قوانین را چک کند و مثل یک کارشناس متالورژی نظر بدهد.
